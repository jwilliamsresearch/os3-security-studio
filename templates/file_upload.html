Insecure File Upload

What is it? File upload vulnerabilities allow attackers to upload malicious files that can compromise the server or other users.

Common Vulnerabilities:
  • No file type validation: Accepting any file type
  • Path traversal: ../ sequences in filenames
  • Executable files: PHP, JSP, ASP scripts
  • Large files: DoS through disk space exhaustion
Attack Vectors:
  • Uploading web shells (PHP, ASP)
  • Path traversal attacks
  • MIME type spoofing
  • Double extension attacks (.jpg.php)
Prevention:
  • File type whitelisting
  • Secure filename handling
  • File size limits
  • Virus scanning
  • Separate upload directory

Dangerous Files (blocked by secure):
  • .php - Web shell scripts
  • .jsp - Java server pages

  • .exe - Executable files
Safe Files (allowed by secure):
  • .txt - Text files
  • .pdf - PDF documents
  • .jpg, .png - Images
  • .doc, .docx - Documents
