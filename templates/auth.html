Insecure Authentication

What is it? Weak authentication allows attackers to gain unauthorized access through various attack vectors.

Common Vulnerabilities:
  • Weak passwords: Short, simple, or common passwords
  • No complexity requirements: Missing uppercase, numbers, symbols
  • Session management: Weak session tokens, no timeout
  • Brute force: No rate limiting or account lockouts
Attack Methods:
  • Password brute force attacks
  • Dictionary attacks
  • Session hijacking
  • Credential stuffing
Prevention:
  • Strong password policies
  • Multi-factor authentication
  • Account lockout mechanisms
  • Secure session management
  • Password hashing (bcrypt, scrypt)
