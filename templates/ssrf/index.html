Server-Side Request Forgery (SSRF)

What is it? SSRF occurs when an application fetches remote resources without validating user-supplied URLs, allowing attackers to make requests on behalf of the server.

Common Attack Vectors:
  • http://localhost:22 - Port scanning internal services
  • http://169.254.169.254/latest/meta-data/ - AWS metadata extraction
  • file:///etc/passwd - Local file access (if supported)
  • http://internal-admin:8080/admin - Internal admin access
Prevention:
  • Whitelist allowed domains and protocols
  • Block private IP ranges and localhost
  • Validate and sanitize URLs
  • Use network segmentation
  • Implement proper firewall rules
