Cross-Site Request Forgery (CSRF)

What is it? CSRF tricks authenticated users into performing unintended actions by exploiting their active session.

How CSRF Works:
  1. User logs into vulnerable site
  2. Attacker tricks user into visiting malicious site
  3. Malicious site sends requests to vulnerable site
  4. Requests execute with user's credentials
Common Attack Vectors:
  • Hidden forms in malicious websites
  • Image tags with harmful URLs
  • AJAX requests from compromised sites
Prevention:
  • CSRF tokens in forms
  • SameSite cookie attributes
  • Referrer header validation
  • Double-submit cookie pattern
