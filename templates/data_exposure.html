Sensitive Data Exposure

What is it? Sensitive data exposure occurs when applications inadequately protect sensitive information like passwords, personal data, or financial records.

Common Vulnerabilities:
  • Unencrypted storage: Plain text passwords in databases
  • Weak encryption: Outdated algorithms (MD5, SHA1)
  • Information leakage: Exposing internal data in responses
  • Insufficient transport security: HTTP instead of HTTPS
Data at Risk:
  • Passwords and authentication credentials
  • Personal identifiable information (PII)
  • Financial and payment data
  • Health records and sensitive documents
Prevention:
  • Strong encryption at rest and in transit
  • Proper data classification
  • Secure key management
  • Data minimization principles

Data Exposure Examples

Common sensitive data that should never be exposed:

Authentication Data:
  • Password hashes
  • Salt values
  • Session tokens
  • API keys
Personal Information:
  • Social security numbers
  • Credit card numbers
  • Phone numbers
  • Home addresses
Learning Objectives
  • Understand what constitutes sensitive data
  • Learn to identify data exposure vulnerabilities
  • Practice proper data filtering techniques
  • Implement data minimization principles
Encryption and Hashing
Secure Password Storage:

This application uses proper password hashing:

from werkzeug.security import generate_password_hash
password_hash = generate_password_hash(password)
What NOT to do:

Never store passwords in plain text or use weak hashing:

# DON'T DO THIS!
password = "plaintext" # ❌
md5_hash = hashlib.md5(password) # ❌
