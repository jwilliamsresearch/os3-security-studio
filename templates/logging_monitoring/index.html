Security Logging and Monitoring Failures

What is it? Insufficient logging, monitoring, and incident response that prevent organizations from detecting and responding to breaches.

Common Problems:
  • Missing Security Logs: Login attempts, access control failures not logged
  • Inadequate Monitoring: No real-time alerting or anomaly detection
  • Poor Log Management: Logs not centralized, searchable, or retained
  • No Incident Response: Lack of response procedures and tools
Best Practices:
  • Log all security-relevant events
  • Implement real-time monitoring and alerting
  • Centralize log management (SIEM)
  • Regular log analysis and threat hunting
  • Incident response procedures

OWASP Top 10 2021: A09 - Security Logging and Monitoring Failures

This vulnerability category covers the lack of security logging, monitoring, and incident response. Key issues include:

Logging Failures:

  • Auditable events not logged
  • Warnings and errors generate inadequate logs
  • Logs stored locally only
  • No log integrity protection

Monitoring Failures:

  • No real-time monitoring
  • No automated alerting
  • Penetration testing undetected
  • Slow incident response

Proper Logging Elements
What to Log:
  • Authentication events: Login, logout, failed attempts
  • Authorization failures: Access denied events
  • Input validation failures: Malformed requests
  • Application errors: Exceptions and failures
  • Administrative changes: Configuration updates
Log Format:
timestamp | level | event | user | ip | details
Monitoring Tools
SIEM Solutions:
