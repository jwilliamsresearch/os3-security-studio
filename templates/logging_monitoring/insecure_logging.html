Insecure Logging

Security Risk: Poor logging practices that fail to detect attacks or expose sensitive information.

Common Issues:
  • Missing Security Events: Not logging authentication failures
  • Excessive Logging: Logging sensitive data like passwords
  • Poor Log Management: No centralization or monitoring
  • Insufficient Context: Missing user context and timestamps
Attack Scenarios:
  • Undetected brute force attacks
  • Privilege escalation goes unnoticed
  • Data exfiltration without alerts
  • Forensic investigation impossible
