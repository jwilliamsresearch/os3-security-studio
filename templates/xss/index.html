Cross-Site Scripting (XSS)

What is it? XSS allows attackers to inject malicious scripts into web pages viewed by other users.

Types of XSS:
  • Stored XSS: Malicious script stored in database
  • Reflected XSS: Script reflected from user input
  • DOM-based XSS: Client-side script modification
Common Payloads:
  • <script>alert('XSS')</script>
  • <img src=x onerror=alert('XSS')>
  • <svg onload=alert('XSS')>
Prevention:
  • Input sanitization and validation
  • Output encoding
  • Content Security Policy (CSP)
  • HTML sanitization libraries
