Educational Summary:
DNS over HTTPS (DoH):
  • Uses standard HTTPS (port 443)
  • Harder to block or filter
  • Better privacy protection
  • Can bypass network restrictions
DNS over TLS (DoT):
  • Dedicated port (853)
  • Easier to identify and manage
  • Lower overhead than DoH
  • Better for enterprise environments
DNSSEC:
  • Cryptographic DNS validation
  • Prevents cache poisoning
  • Ensures response authenticity
  • Detects tampering attempts
