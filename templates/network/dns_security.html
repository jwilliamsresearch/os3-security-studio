DNS Security

What is DNS? Domain Name System translates human-readable domain names into IP addresses that computers use to identify each other.

DNS Vulnerabilities:
  • Cache Poisoning: Injecting false DNS records into resolver cache
  • DNS Tunneling: Using DNS queries to exfiltrate data or establish command channels
  • DNS Hijacking: Redirecting DNS queries to malicious servers
  • Amplification Attacks: Using DNS servers for DDoS amplification
Security Measures:
  • DNSSEC: Cryptographic signatures for DNS records
  • DNS over HTTPS (DoH): Encrypted DNS queries over HTTPS
  • DNS over TLS (DoT): Encrypted DNS queries over TLS
  • DNS Filtering: Blocking known malicious domains

DNS Process
How DNS Resolution Works:
  1. Browser Cache: Check local browser cache
  2. OS Cache: Check operating system cache
  3. Router Cache: Check local router cache
  4. ISP Resolver: Query ISP's DNS resolver
  5. Root Servers: Query root DNS servers
  6. TLD Servers: Query top-level domain servers
  7. Authoritative: Query authoritative name servers
Each step in this process can be a potential attack vector!
