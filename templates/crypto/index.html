Cryptographic Failures

What is it? Cryptographic failures occur when applications use weak encryption, poor key management, or broken cryptographic algorithms, leading to data exposure.

Common Vulnerabilities:
  • Weak Hashing: MD5, SHA1 without salt
  • Hardcoded Keys: Encryption keys in source code
  • Weak Encryption: DES, RC4, custom algorithms
  • Poor Key Management: Predictable keys, key reuse
Prevention:
  • Use strong hashing (bcrypt, Argon2, PBKDF2)
  • Implement proper key management
  • Use proven encryption algorithms (AES)
  • Generate cryptographically secure random keys
  • Salt all password hashes

Key Concepts

Weak Crypto Examples:

  • MD5 password hashing
  • Hardcoded encryption keys
  • XOR "encryption"
  • No salt for password hashes

Strong Crypto Examples:

  • bcrypt/Argon2 password hashing
  • PBKDF2 key derivation
  • AES encryption with HMAC
  • Cryptographically secure random keys
Learning Objectives
  • Understand common cryptographic vulnerabilities
  • Learn the difference between weak and strong crypto
  • Practice implementing secure encryption and hashing
  • Recognize the importance of proper key management
