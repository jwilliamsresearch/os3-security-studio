Insecure Cryptography

Security Risk: This page demonstrates weak cryptographic practices that can be easily exploited by attackers.

Vulnerabilities Shown:
  • MD5 Hashing: Fast but weak, vulnerable to rainbow tables
  • Hardcoded Keys: Encryption keys stored in source code
  • No Salt: Password hashes without random salt
  • Weak Encryption: Simple XOR cipher
Attack Vectors:
  • Rainbow table attacks on MD5 hashes
  • Brute force attacks on weak passwords
  • Key extraction from source code
  • Pattern analysis on XOR encryption

Warning: Insecure Cryptography

This demonstration uses intentionally weak cryptographic practices. Never use these methods in production!

Weak Password Hashing

Using MD5 without salt - easily crackable with rainbow tables:

Code:
md5_hash = hashlib.md5(password.encode()).hexdigest()
Weak Encryption

Using hardcoded key with simple XOR cipher:

Code:
key = "hardcoded_key"
encrypted = xor_encrypt(data, key)
Vulnerability Analysis
How to Exploit:

MD5 Hash Cracking:

  1. Copy the MD5 hash from above
  2. Use online MD5 crackers or rainbow tables
  3. Common passwords crack instantly
  4. Example: 5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8 = "password"

XOR Cipher Breaking:

  1. Analyze the encrypted output patterns
  2. Try common key lengths (8, 16, 32 chars)
  3. Use frequency analysis
  4. Brute force short keys
