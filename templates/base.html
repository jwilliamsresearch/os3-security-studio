SQL Injection

Unvalidated database queries allowing data extraction/manipulation through malicious input.

Cross-Site Scripting (XSS)

Script injection attacks that execute malicious code in user browsers.

CSRF

Unauthorized actions performed using an authenticated user's credentials.

Insecure Authentication

Weak password policies and poor session management practices.

Insecure File Upload

Unrestricted file types and path traversal vulnerabilities in upload functionality.

Broken Access Control

Privilege escalation and unauthorized access to restricted resources.

Sensitive Data Exposure

Unencrypted storage and weak cryptographic implementations.

Security Misconfiguration

Default credentials and unnecessary features left enabled.
