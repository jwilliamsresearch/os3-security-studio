Broken Access Control

What is it? Access control vulnerabilities allow users to access resources or perform actions beyond their intended permissions.

Common Vulnerabilities:
  • Direct object references: Accessing resources by ID manipulation
  • Missing authorization: No permission checks
  • Privilege escalation: Users gaining admin rights
  • Forced browsing: Accessing restricted URLs directly
Attack Methods:
  • URL parameter manipulation
  • Session token modification
  • Role/privilege bypass
  • Horizontal privilege escalation
Prevention:
  • Proper authorization checks
  • Role-based access control (RBAC)
  • Principle of least privilege
  • Input validation and sanitization
